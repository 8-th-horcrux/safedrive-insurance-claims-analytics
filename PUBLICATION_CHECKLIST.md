- [ ] Confirm no personal/customer/policyholder information, secrets, tokens, credentials, or local machine paths are exposed.
- [ ] Keep raw row-level datasets, scored policy-level exports, MLflow database, and serialized model binaries out of this public repo.
- [ ] Open all notebooks and check outputs for identifying or confidential data before publishing.
- [ ] Confirm the app starts locally with `streamlit run app.py`.
- [ ] Check that the risk bands are described as percentile-ranked groups, not calibrated thresholds.
- [ ] Describe the model as a prototype; do not claim validated next-90-day prediction, savings, or claim reduction.
- [ ] Test the GitHub and Streamlit URLs in a private browser window.
